3Technical Challenges & Explanation Report

C1Long-horizon operator learning is chaotic

The first surrogate, trained on a T=4 horizon, memorized the training set (train MSE 5.5Ã—10â»â´) yet generalized at 17% â€” best validation at epoch 6 of 100. A T=4 one-shot map spans an entire coarsening cascade whose merger outcomes depend sensitively on the input. Resolution: horizon shortened to T=1 where the operator is well-conditioned; longer horizons via autoregressive composition are future work. Documented as a config-level decision.

C2A hidden-parameter bug that later became the experiment

Even at T=1, 11% error with instant overfitting. Root cause: the PDE parameter Îµ was not a model input and is not inferable from the other channels â€” the target literally wasn't a function of the inputs. Resolution: Îµ fed as a constant channel (standard parametric-FNO practice) â†’ error collapsed 60Ã— to 1.5%. Instructive symmetry: the same hidden-variable structure that was a bug in Phase 2 is deliberately constructed in Phase 4, where its training signature reappears by design.

C3Physics checks mis-specified for a finite box

The textbook coarsening exponent (â„“ ~ tÂ½) is unmeasurable in a unit box â€” no scaling decade exists, and the structure-factor length is biased by the Porod tail. C4Nyquist handling in spectral resampling

Naive Fourier truncation/zero-padding broke the exact resample round trip (2.6% error) by mishandling the ambiguous Nyquist bin. Resolution: Nyquist-splitting resampling matrices â€” round trip now exact, validator targets alias-free.

C5The compute wall

Single-threaded NumPy solves projected ~14 h for one dataset + validator set. Resolution: float32 CUDA backends for both solvers (~100Ã—; 25 min total), with the float64 NumPy path retained as the verified reference and cross-backend agreement unit-tested (<10â»â´). C6Ecosystem breakage

SALib 1.5.1 passes problem names into pd.unique, which pandas 3.0 no longer accepts for plain lists. Resolution: one-line fix (names as ndarray), noted for future SALib use.

C7Two audit checks were initially mis-formalized

(i) Requiring the multivariate probe's causal coefficient to be stable across environments is not what ICP predicts â€” with a shortcut available, a full-representation fit legitimately shifts weight from causal to spurious directions; that reweighting is itself evidence of adoption.
